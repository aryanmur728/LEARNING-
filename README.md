# Fluent — English practice

A small, self-contained English practice website. It uses plain HTML, CSS, and JavaScript; no build tools or packages are needed.

## Open in VS Code

1. Open the `english-practice` folder in VS Code (`File → Open Folder…`).
2. Open `index.html` and choose **Open with Live Server** if you have the Live Server extension installed.
3. Or open `index.html` directly in your browser. The chat demo works without a server.

## Files

- `index.html` — page structure
- `styles.css` — layout and visual styles
- `app.js` — chat demo, voice input, lesson and navigation interactions

The tutor replies are sample front-end responses and are not connected to a live AI service. Voice input uses the browser's built-in speech recognition when available.
